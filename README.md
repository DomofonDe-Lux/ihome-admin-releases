# i-Home Admin — релізи

Інсталятори програми i-Home Admin і файли автооновлення. Цей репозиторій містить лише готові збірки, без вихідного коду. Релізи публікуються автоматично.

## Завантаження

**[→ Остання версія](https://github.com/DomofonDe-Lux/ihome-admin-releases/releases/latest)**

У розділі **Assets** оберіть файл для своєї системи:

| Система | Файл |
|---|---|
| Windows 10/11 (64-біт) | `ihome-admin_<версія>_x64-setup.exe` |
| macOS (Apple M1–M5) | `ihome-admin_<версія>_aarch64.dmg` |

Інші файли (`.app.tar.gz`, `.sig`, `latest.json`) — службові, для автооновлення. Завантажувати їх не потрібно.

## Встановлення

- **Windows:** запустіть `.exe`. Якщо брандмауер спитає дозвіл для `ihome-backend`, дозвольте для приватної мережі, інакше панелі не підключаться.
- **macOS:** відкрийте `.dmg`, перетягніть програму в «Програми» і запускайте звідти, а не з вікна `.dmg`.

## Оновлення

Встановлена програма оновлюється сама: ⚙ → **Про програму** → **Перевірити оновлення**.
