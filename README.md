# i-Home Admin — релізи

Інсталятори програми i-Home Admin і файли автооновлення.
Цей репозиторій містить лише готові збірки, без вихідного коду. Релізи публікуються автоматично.

- Windows: `ihome-admin_<версія>_x64-setup.exe`
- macOS: згодом

Встановлену програму оновлюйте через ⚙ → «Перевірити оновлення».
