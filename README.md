# i-Home Admin — releases

Installers and auto-update files for i-Home Admin. This repository contains only ready builds, no source code. Releases are published automatically.

## Download

**[→ Latest version](https://github.com/DomofonDe-Lux/ihome-admin-releases/releases/latest)**

In the **Assets** section choose the file for your system:

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `ihome-admin_<version>_x64-setup.exe` |
| macOS (Apple M1–M5) | `ihome-admin_<version>_aarch64.dmg` |

Other files (`.app.tar.gz`, `.sig`, `latest.json`) are used by auto-update. You don't need to download them.

## Install

- **Windows:** run the `.exe`. If the firewall asks about `ihome-backend`, allow it for private networks, otherwise panels can't connect.
- **macOS:** open the `.dmg`, drag the app to Applications and run it from there, not from the `.dmg` window.

## Update

The installed app updates itself: ⚙ → **About** → **Check for updates**.

# i-Home Admin — релізи

Інсталятори програми i-Home Admin і файли автооновлення. Лише готові збірки, без вихідного коду.

**[→ Остання версія](https://github.com/DomofonDe-Lux/ihome-admin-releases/releases/latest)** → розділ **Assets**:

| Система | Файл |
|---|---|
| Windows 10/11 (64-біт) | `ihome-admin_<версія>_x64-setup.exe` |
| macOS (Apple M1–M5) | `ihome-admin_<версія>_aarch64.dmg` |

Інші файли (`.app.tar.gz`, `.sig`, `latest.json`) — службові, для автооновлення.

- **Windows:** запустіть `.exe`. Якщо брандмауер спитає дозвіл для `ihome-backend`, дозвольте для приватної мережі.
- **macOS:** відкрийте `.dmg`, перетягніть програму в «Програми» і запускайте звідти.

Оновлення: ⚙ → **Про програму** → **Перевірити оновлення**.
